# Hanime-AG Premium

# UI / UX Blueprint

Version: 1.0

This document defines the complete user interface and user experience of Hanime-AG Premium.

Every page must follow this blueprint.

The platform should feel like a premium streaming service with cinematic quality while maintaining its own original identity.

---

# Overall Design Style

Mood:
- Premium
- Modern
- Cinematic
- Minimal
- Elegant
- Fast
- Responsive

Design Inspiration:
- Netflix
- Apple TV
- Disney+
- Crunchyroll

Do not copy these platforms.

Create an original experience inspired by their quality.

---

# Layout

Desktop:
- Sticky top navigation
- Large cinematic hero banner
- Horizontal content carousels
- Smooth scrolling
- Large spacing
- Glassmorphism overlays
- Animated hover effects

Tablet:
- Optimized spacing
- Responsive grid
- Touch friendly controls

Mobile:
- Thumb-friendly navigation
- Bottom navigation
- Swipe gestures
- Full-width content cards
- Optimized loading speed

# UI Rule

Before redesigning any page:

1. Analyze the existing page.
2. Improve instead of replacing.
3. Preserve completed work.
4. Maintain visual consistency.
5. Follow PROJECT_BLUEPRINT.md.

This document is the official UI and UX specification for Hanime-AG Premium.
