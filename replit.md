# Hanime AG

A static anime/hanime content tracker site with a dark-themed UI.

## Stack
- Pure HTML, CSS, and vanilla JavaScript (no build step)
- Static file server: `serve` (npm global)

## Pages
- `index.html` — Home / landing page
- `anime.html`, `donghua.html`, `hanime.html`, `movies.html`, `series.html`
- `gallery.html`, `favorite.html`, `watch.html`, `account.html`, `trending.html`
- `nightworld.html`, `shadowhero.html`, `bluesky.html`

## Running
The workflow `Start application` serves the project on port 5000 via `npx serve . -p 5000 -s`.
No build step required — edit HTML/CSS/JS files directly.
