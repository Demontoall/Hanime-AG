# Vision

Hanime-AG Premium is a next-generation streaming platform inspired by Netflix's cinematic experience while establishing its own unique identity for anime, donghua, movies, and TV series.

The goal is to create a premium entertainment platform that feels modern, elegant, fast, and production-ready across desktop, mobile, tablet, and future smart TV applications.

Every design decision should prioritize user experience, visual quality, performance, and scalability.

This document is the single source of truth for the project. Before implementing any feature, the development agent must review this blueprint and continue from the existing codebase without restarting or replacing completed work.

---

# Core Principles

- Never rebuild completed features.
- Improve existing functionality rather than replacing it.
- Preserve backward compatibility whenever possible.
- Maintain a consistent design language.
- Prioritize mobile-first responsive design.
- Optimize performance for fast loading and smooth animations.
- Keep the code modular, maintainable, and scalable.
- Follow modern web development best practices.

# Design Philosophy

The website should feel like a premium streaming platform inspired by Netflix while maintaining its own original identity.

The experience should be:

- Elegant
- Minimal
- Cinematic
- Smooth
- Modern
- Fast
- Immersive

Avoid clutter and unnecessary elements.

Every animation should feel intentional.

Every page should have visual consistency.

# Development Rule

Before building any new feature:

1. Analyze the current project.
2. Determine what already exists.
3. Preserve completed work.
4. Extend existing functionality.
5. Do not redesign working pages unless there is a clear improvement.
6. Follow this blueprint as the project's master specification.

This blueprint overrides previous design decisions unless explicitly updated.
